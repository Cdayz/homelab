# Nomad Jobs

Папка со всеми nomad jobs необходимыми для HomeLab.

Формат директории под приложение

- `jobs/<app>`
  - `configs/` - папка с конфигурационными файлами которые монтируются в приложение as-is
  - `secrets/` - папка с sops-encrypted секретами - которые расшифровываются перед деплоем и рендерятся на сервер
    - `secrets/*.raw.yaml` - файлы с расшифрованными секретами (не попадают в git)
    - `secrets/*.yaml` - файлы с sops-encrypted секретами - идут в git
  - `volumes/` - папка с volumes которые нужны приложению
    - `volumes/*.hcl` - описания volume'ов
    - `volumes/*.zfs.properties` - если volume это zfs-том на CSI, то этот файл описывает дополнительные zfs-опции для тома
  - `job.hcl` - декларация приложения со всем ему необходимым
